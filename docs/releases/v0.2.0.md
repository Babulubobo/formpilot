## FormPilot v0.2.0

First packaged release / 首个打包发布版本

[Download FormPilot-chrome.zip / 下载扩展包](https://github.com/Babulubobo/formpilot/releases/download/v0.2.0/FormPilot-chrome.zip)

### 中文

FormPilot 是浏览器里的答题助手：读取网页题目与选项，由 AI 作答，再完成选择和填写。

**本版本包含**

- 支持原生表单控件、ARIA 单选组及部分按钮和链接式选项；对不明确的题目结构进行 AI 判断与有限重试。
- JEV 优先判断选择题，DeepSeek 回答文字题并复核不确定的选项，参考资料全部选填。
- 自动翻页、保留已有答案、停止控制和执行记录，默认在最终提交前暂停。
- 改进菜鸟教程与 IndiaBIX 题目、选项的识别。
- 中英文界面、白天 / 黑夜 / 跟随系统外观、本机保存 API Key 与设置。
- MIT 许可证及独立的免责声明。

**安装与更新**

1. 下载附件 **FormPilot-chrome.zip**，解压到一个长期保留的文件夹。
2. 在 Chrome 116 或更新版本打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的解压目录。
4. 打开题目网页，点击 FormPilot 图标，在设置中配置 TypeSafe 和 DeepSeek API Key，再点击「开始填写」。

已安装用户：把包内文件更新到原安装目录，点击扩展卡片上的刷新按钮，再刷新网页并重新打开侧栏。保留原安装路径，不要先卸载，以保留已有设置。

本包只包含扩展运行文件、许可证和免责声明。GitHub 自动提供的 **Source code** 附件包含完整项目与本地演示。当前没有商店安装或自动更新功能。

**支持边界与验证**

尚不支持 iframe、Shadow DOM、图片 / Canvas 题目、验证码或文件上传。特殊网页仍可能无法识别，AI 答案需要核对。本次运行的 25 项 Node 测试均通过，打包产物经过完整性与扩展加载检查；未使用真实模型测试答题准确率。

### English

FormPilot is an in-browser quiz assistant: it reads questions and options, uses AI to answer them, then selects or fills responses on the page.

**Included in this release**

- Native form controls, ARIA radio groups and some button- or link-based options, with AI structure recovery and a bounded retry for ambiguous questions.
- JEV handles choices first; DeepSeek answers text questions and checks uncertain choices. Reference details are optional.
- Auto-advance, preservation of existing answers, stop controls and an activity log. Final submission is disabled by default.
- Improved question and option detection for Runoob and IndiaBIX.
- Chinese and English interfaces, Light / Dark / System themes, and local storage for API keys and settings.
- The MIT License and a separate disclaimer.

**Install and update**

1. Download **FormPilot-chrome.zip** from the assets and extract it into a folder you will keep.
2. In Chrome 116 or later, open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Open a question page, click the FormPilot icon, configure your TypeSafe and DeepSeek API keys in settings, then click **Fill form**.

Existing users: replace the files in the original installation folder, reload the extension, refresh the page and reopen the side panel. Keep the original path and do not uninstall first, so settings are retained.

The package contains extension runtime files, the license and the disclaimer. GitHub's **Source code** assets contain the full project and local demo. Store installation and automatic updates are not available yet.

**Limitations and validation**

Iframes, Shadow DOM, image / Canvas questions, CAPTCHAs and file uploads are not supported. Unusual layouts may still fail, and AI answers need review. All 25 Node tests passed for this release; the package was checked for completeness and extension loading. Answer accuracy was not tested with live models.
