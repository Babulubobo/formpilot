## FormPilot v0.2.4

[Download FormPilot-chrome.zip / 下载扩展包](https://github.com/Babulubobo/formpilot/releases/download/v0.2.4/FormPilot-chrome.zip)

### 中文

- 加快连续答题：复用已确认的题目布局，每题仍读取当前题干和选项，减少重复的 AI 结构识别。
- 改进通用题目与选项识别，TypeSafe 无法确认的结构交由 DeepSeek 复核。
- 支持“检查答案 → 下一题”的答题流程，保留已判分答案，修复填写完成后未继续翻页的问题。
- 加强旧页面扫描、选项缺失与布局变化的校验，默认在最终提交前暂停。
- 中英文 README 新增实际操作 GIF 演示。

**安装与更新**

下载附件 **FormPilot-chrome.zip** 并解压。在 Chrome 116 或更新版本打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。

已安装用户：把包内文件更新到原安装目录，点击扩展卡片上的刷新按钮，再刷新题目网页并重新打开侧栏。保留原安装路径，不要先卸载，以保留设置。

**验证**：28 项 Node 测试及浏览器回归检查通过。连续答题性能检查使用确定性模型响应，不代表真实 API 延迟或答题准确率；AI 答案仍需核对。

### English

- Speed up consecutive questions by reusing confirmed layouts while reading the current question and options on every step.
- Improve general question and option recognition, with DeepSeek reviewing structures that TypeSafe cannot confirm.
- Support Check → Next flows, preserve graded answers, and fix pages that stopped after filling.
- Strengthen stale-scan, missing-option and layout-change checks. Pause before final submission by default.
- Add a recorded GIF demonstration to both READMEs.

**Install or update**

Download **FormPilot-chrome.zip** and extract it. In Chrome 116 or later, open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the folder containing `manifest.json`.

Existing users: replace the files in the original installation folder, reload the extension, refresh the quiz page and reopen the side panel. Keep the same folder and do not uninstall first, so settings are retained.

**Validation**: 28 Node tests and browser regression checks passed. Navigation performance checks use deterministic model responses and do not measure live API latency or answer accuracy. Review AI-generated answers.
