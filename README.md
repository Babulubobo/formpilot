# FormPilot · 填表助手

一个可直接加载的 Chrome Manifest V3 侧栏扩展：读取当前网页的题目和说明，JEV 批量理解字段与选择选项，DeepSeek 解题、推理与起草开放题答案，页面脚本执行并检查结果。无需事先提供整份答案；参考资料只用于补充用户事实与填写要求。生产运行无 npm 依赖，也不需要本地浏览器代理。

## 先体验

1. 在本目录运行 `npm run demo`，打开 <http://127.0.0.1:4173/demo/>。
2. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」。选择本项目的 **extension** 文件夹。
3. 回到演示网页，点击浏览器工具栏的 FormPilot 扩展图标。扫描时若出现「授权此网站并扫描」，点击并在 Chrome 的确认框中允许该网站。
4. 无需 API Key 的演示：展开「设置与资料」，在运行选项中选择「本地演示（不调用 AI）」，再展开「参考资料」并点击「载入示例资料」，然后「开始填写」。默认会自动翻页，停在最终提交前。载入示例资料不会切换运行模式。
5. 要体验包括提交在内的完整流程，在运行选项中勾选「允许最终提交」后再开始。演示页面的提交仅显示本地结果，不向外部发送数据。

演示共有 **2 页、16 道题、18 个可填写字段**（兴趣题有 3 个独立复选框）。演示模式使用固定规则，不调用 JEV 或 DeepSeek，不能代表模型速度或准确率。示例人物「林澈」及项目「Seed Studio」均为虚构。

## 真实模型模式

1. 「参考资料」全部选填，可以全部留空直接开始。知识题、阅读理解、方案设计和可起草的开放题由模型自己回答；可以提供一句填写要求或项目背景让答案更贴切，不用预先写好答案。
2. 展开「设置与资料」，在「模型连接」中填入自己的 TypeSafe 和 DeepSeek API Key。
3. 切换至「AI 自动填写」，点击「保存资料与设置」。JEV 使用 `jev-latest`；DeepSeek 从下拉框选择 Flash（默认，`deepseek-flash`）或 V4 Pro（`deepseek-v4-pro`），均关闭思考模式。模型名称不能自由输入，旧版保存的未知型号会回到默认选项。
4. 在目标表单页点击 FormPilot 扩展图标，再开始填写。也可以先在配套的本地问卷上验证模型效果。

JEV 在每轮请求中批量判断字段；精确的事实字段可直接复制，选择题可以依据题干、页面说明或一般知识选择。JEV 对单选题/下拉题置信度低于 `0.8` 或返回 `skip` 时，会把题干和全部选项交给 DeepSeek 再判断一次，与待回答的文本题合并为一次请求。执行记录会逐题显示转交原因、初次 choice 和置信度，区分低于阈值与返回 skip；选择题的判断说明与文本生成说明分开。DeepSeek 只能返回网页已有选项的 ID，不能凭空添加选项；仍无法作答时返回原因，在侧栏状态与执行记录中显示。文本知识题、推理题、方案与开放题也由 DeepSeek 作答。申请理由和预期用途可以起草为计划或期望；未知真实姓名、邮箱、已有经历、实际公司数据和明确同意不会编造。当前任务内的已填答案会保留来源并传入后续页面，帮助回答保持一致。必填项或选择题仍未回答时停止翻页。`0.8` 是原型的暂定判断阈值，未经真实问卷校准，也不是正确率承诺。

验证无需资料的模型作答：打开 <http://127.0.0.1:4173/demo/knowledge.html>，将参考资料留空，配置 API Key 并选择「AI 自动填写」，点击「开始填写」。此页包含知识题、三步方案、试用理由、页面理解选择题及未知邮箱；它没有固定演示答案，真实作答需要调用模型。

资料、设置与 API Key 保存在扩展的本机存储，点击「保存资料与设置」或「开始填写」时保存。更新或重新加载同一个扩展、重启浏览器后仍保留，不通过 Chrome Sync 同步到其他设备。Key 与用户参考资料分开保存，存储仅允许扩展自身页面与后台访问，网页内容脚本不能读取。清空 Key 输入框并保存即可移除；卸载扩展也会清除其本机数据。真实模式会将本轮字段和所填资料发送至对应的模型服务，Key 仅用于对应服务的请求认证。最终提交授权只对当前侧栏会话生效，不持久保存。

## 支持范围

- 主页面内的原生文本、邮箱、网址、电话、数字、日期、textarea、单选下拉框、单选组和复选框。
- 根据明确的「下一页 / 下一步 / Continue / Next」按钮自动翻页；按钮不明确或有多个候选时停止。
- 保留已有非空内容和已勾选项；不自动覆盖用户在模型等待期间编辑的答案。
- 单选题或下拉选项仍未作答时停止翻页，即使网页没有标为必填；整页没有可用答案时也会停止，不空白提交。
- 每次换文档后重新处理字段，支持测验通过同一个网址提交并加载下一题的情况。
- 单选题会读取同组选项之前的邻近题干，支持标题、普通段落、div/span 和文本节点；不会越过其它问题的控件去套用页面总标题。
- 忽略站内搜索框。支持菜鸟教程使用的 jQuery Quiz 链接式选项：自动开始测验，读取当前可见题目并保留代码缩进，选择后继续下一题；最终「完成」仍受提交开关控制。
- 支持 IndiaBIX 在线测验的分栏选项，读取按钮旁相邻容器中的真实答案文字；只处理测验题目，排除搜索、草稿区和成绩反馈表单，最终提交仍受开关控制。网站弹出提交确认时需在网页中确认。
- 填写后检查实际值及网页原生校验，支持常见使用原生控件的 React 表单。
- 任务固定在开始时的页面；切换标签页或关闭侧栏会停止任务。已完成的填写会保留，再次开始重新扫描。

除上述已适配的测验外，当前暂不处理其他自定义选项、iframe、Shadow DOM、自定义 ARIA 控件、多选下拉框、文件上传、密码、验证码或跨站连续任务。每次最多处理 80 个字段、运行 20 轮。普通页面点击提交后只报告「已点击提交」，不把它当作服务器已接受的证明。

工具栏点击使用 Chrome 的 `activeTab` 临时授权。若从侧栏入口打开、新建标签或跨站后没有页面权限，扫描会显示「授权此网站并扫描」，通过 Chrome 确认框只申请当前网站的访问权限。`tabs` 权限用于读取目标标签的地址与标题，本身不允许读写网页；普通网站的访问权限按需申请，不在安装时授予全部网站。网站授权可以在 Chrome 扩展详情中撤回。原型另外连接 TypeSafe / DeepSeek 两个官方 API 域名。

若安装过旧版本，请到 `chrome://extensions` 点击扩展卡片上的刷新按钮，确认名称为 **FormPilot**、版本为 **0.1.14**，刷新正在测试的网页，然后关闭旧侧栏并重新打开；侧栏底部也会显示版本。沿用原来的 extension 文件夹更新，已保存的资料与 API Key 会保留。

侧栏默认突出当前页面和「开始填写」，无需先扫描。运行时主按钮切换为「停止填写」，识别到字段或产生执行记录后才显示结果区。模型、运行选项和选填资料统一收在「设置与资料」中；主按钮下始终显示翻页与提交策略。首次使用若未配置必需的 TypeSafe Key，点击开始会自动打开设置并定位到输入框。

侧栏采用中性黑白灰配色。「设置与资料」内可选择「白天 / 黑夜 / 跟随系统」，切换后立即保存；默认跟随系统，系统外观变化时会自动切换，手动选择白天或黑夜则保持该模式。

侧栏右上角可直接点击「中文 / EN」切换语言，实色按钮表示当前语言；支持键盘 Tab 聚焦、Enter 或空格选择。首次使用跟随浏览器语言，之后记住手动选择。按钮、设置、执行状态和系统错误均提供中英文；网页题目、用户资料和已填答案保持原文。任务运行中语言选择暂时禁用，结束后可切换。Chrome 自身显示的扩展名称和工具栏提示跟随浏览器界面语言。

## 验证

仓库只包含源码、虚构演示资料与测试用占位密钥。真实 API Key 在扩展设置中填写；运行 `jev.mjs` 时使用环境变量 `TYPESAFE_API_KEY`。请勿把真实密钥写入源码。环境文件、私钥、本地工具配置、日志与测试截图已加入 Git 忽略规则。

```sh
npm test
```

核心测试使用 Node 自带的测试框架，覆盖返回值校验、批量模型调用、错误消息处理、已有值保护、缺失必填项、停止、提交开关与翻页反馈。

浏览器验证需要本机有 Playwright 和它的 Chromium：

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

浏览器测试使用临时服务器和独立浏览器配置。首先加载未修改权限的扩展副本，实际触发 Chrome 的无权限注入失败，验证目标地址、网站授权入口、拒绝授权、授权期间换页及内部页提示；原生权限确认框的选择使用模拟结果。然后在另一个临时配置中仅预授予 `127.0.0.1` 权限，验证真实 DOM 注入、本地问卷、侧栏、资料保存及模拟 API 请求链路。生产 manifest 不包含这项预授权，测试不会调用真实模型。截图输出到 `test-results/`。

如果已有工具环境提供 Playwright，可用 `PLAYWRIGHT_MODULE_PATH` 指向其 `index.mjs`，用 `PLAYWRIGHT_BROWSERS_PATH` 指定浏览器缓存目录。

## 文件

- `extension/manifest.json` / `background.js`：扩展权限、侧栏入口与存储隔离。
- `extension/content.js`：读取页面、填写控件和执行点击。
- `extension/brain.js`：演示规则、JEV 判断、DeepSeek 文字生成及选项复核。
- `extension/runner.js`：填写、校验、翻页、停止与提交控制。
- `extension/sidepanel.*` / `i18n.js` / `_locales/`：侧栏界面、交互及中英文本地化。
- `demo/`：本地模拟问卷。
- `jev.mjs`：原有 API 示例，保持原样。

接口依据：[TypeSafe API](https://docs.typesafe.ai/api)、[Choice](https://docs.typesafe.ai/primitives/choice)、[Confidence](https://docs.typesafe.ai/confidence)、[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[Chrome Side Panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)。
